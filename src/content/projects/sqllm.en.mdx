## Summary

SQLLM is an interactive web application designed to compare and experiment with three AI technologies applied to databases: Vector Search, natural language query generation (Text-to-SQL), and Retrieval-Augmented Generation (RAG). The application provides a Streamlit interface to test these technologies in real-time with different database backends.

---

## Context and Objectives

With the emergence of generative AI and embeddings, databases are evolving to natively integrate semantic search and query generation capabilities. This project explores and compares these new features through:

- **Accessibility**: Making database AI technologies understandable and testable
- **Comparison**: Evaluating the performance of different backends (ChromaDB, PostgreSQL+pgvector, SQLite-vec, MongoDB)
- **Practical Demonstration**: Allowing experimentation with concrete examples and real-time benchmarks

The main objective was to create a complete demonstration platform illustrating how AI transforms the interaction with databases, from semantic search to natural language query generation.

## Main Features

### 1. Comparative Vector Search
- **Multi-backend**: Simultaneous comparison of 4 vector search solutions
  - ChromaDB: Lightweight local vector database
  - PostgreSQL + pgvector: Vector extension for relational databases
  - SQLite + sqlite-vec: Ultra-lightweight embedded solution
  - MongoDB: NoSQL vector search
- **Automatic Embeddings**: Generation via Sentence Transformers (all-MiniLM-L6-v2)
- **Real-time Benchmarks**: 
  - Indexing time (documents/second)
  - Search latency (milliseconds)
  - Throughput (queries per second)
- **Semantic Search**: Natural language queries with similarity scoring
- **Results Export**: Download benchmarks in CSV format

### 2. Text-to-SQL with AI
- **Dynamic Generation**: Use of Ollama (local LLM) to convert natural language into SQL
- **Demo Mode**: Pre-defined examples to test without an LLM
- **Demo Database**: Pre-filled client/product/order schema
- **Real-time Execution**: Immediate generation and execution of SQL queries
- **Solution Comparison**: Summary table of Text-to-SQL approaches
  - Oracle Select AI (integrated 23ai)
  - pgEdge NL Agents (PostgreSQL extension)
  - SQL Server 2025
  - MongoDB Compass

### 3. RAG (Question-Answering)
- **Complete RAG Pipeline**:
  1. **Indexing**: Documents stored in ChromaDB with embeddings
  2. **Retrieval**: Searching for the most relevant passages
  3. **Augmentation**: Building the context for the LLM
  4. **Generation**: Response generated by Ollama with source citations
- **Knowledge Base**: 5 technical documents on vector databases
- **Mode without LLM**: Direct display of relevant passages if Ollama is unavailable
- **Detailed Metrics**: Retrieval and generation times displayed separately
- **Highlighting**: Retrieved documents visible with their metadata

## Technologies Used

### Backend
- **Python 3.8+**: Main language
- **Streamlit**: Web framework for interactive data science applications
- **Ollama**: Local LLM for generation (llama3.2:1b)
- **Sentence Transformers**: Embedding generation (all-MiniLM-L6-v2, 384 dimensions)

### Vector Databases
- **ChromaDB**: Pure Python vector database
- **PostgreSQL + pgvector**: Vector extension for PostgreSQL 15+
- **SQLite + sqlite-vec**: SQLite vector extension
- **MongoDB**: Atlas Vector Search

### Visualization and Benchmarks
- **Pandas**: Data manipulation and table display
- **Plotly**: Interactive charts for benchmarks
- **BenchmarkTracker**: Custom performance tracking module

### Infrastructure
- **Docker Compose**: Deployment of PostgreSQL and MongoDB
- **psycopg2**: PostgreSQL connector with JSONB support
- **pymongo**: Official MongoDB driver

## Installation

### Prerequisites
```bash
# Python 3.8+
# 2GB RAM minimum
# Docker (optional, for PostgreSQL/MongoDB)
# Ollama (optional, for Text-to-SQL and RAG)
```

### Dependency Installation

```bash

# Clone the repository

git clone [https://github.com/Youxise/SQLLM.git](https://github.com/Youxise/SQLLM.git)

cd SQLLM

# Create a virtual environment

python -m venv .venv

source .venv/bin/activate  # Windows: .venv\Scripts\activate

# Install dependencies

pip install -r requirements.txt

```

### Starting Services (Optional)

```bash

# Launch PostgreSQL and MongoDB with Docker

docker-compose up -d

# Install Ollama (for Text-to-SQL and RAG)

# Download from [https://ollama.ai](https://ollama.ai)

ollama pull llama3.2:1b

```

### Launching the Application

```bash

streamlit run app.py

```

The application will be accessible at http://localhost:8501

## Usage

### Module 1: Vector Search

1. Select backends: Check ChromaDB, SQLite, PostgreSQL, MongoDB

2. Index documents: Click "Index in all selected backends"

3. Ask a question: Enter a natural language query (e.g., "What is a vector database?")

4. Compare results: View search times and documents returned by each backend

5. Export benchmarks: Download the performance CSV

### Module 2: Text-to-SQL

1. Choose the mode:

    - "Write a question": Dynamic generation with Ollama

    - "Pre-defined examples": Pre-written SQL queries

2. Ask a question in natural language: E.g., "Top 3 customers by spending"

3. Generate and execute: The SQL is generated, displayed, and executed automatically

4. Consult results: Table of returned data

### Module 3: RAG Q&A

1. Index the knowledge base: Click "Index documents"

2. Ask a question: E.g., "How to install pgvector in PostgreSQL?"

3. Choose the mode:

    - With Ollama: Automatically generated response

    - Without Ollama: Display of relevant passages only

4. Consult the response: Contextualized response with source citations and metrics
