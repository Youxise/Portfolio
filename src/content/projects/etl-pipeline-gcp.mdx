## Résumé

Ce projet démontre la mise en place d'un pipeline ETL (Extract, Transform, Load) complet sur Google Cloud Platform. Le système génère des données fictives d'employés, les stocke dans Google Cloud Storage, applique des transformations de sécurité et de nettoyage via Cloud Fusion, puis charge les données dans BigQuery pour une visualisation finale avec Looker Studio. Ce projet illustre les bonnes pratiques de traitement de données sensibles dans le cloud.

---

## Contexte et Objectifs

Dans le contexte de l'analyse de données d'entreprise, il est crucial de mettre en place des pipelines robustes et sécurisés pour traiter les informations sensibles des employés. Ce projet avait pour objectifs de :

- **Démontrer la maîtrise des services Google Cloud** pour le traitement de données à grande échelle
- **Implémenter les meilleures pratiques de sécurité** : chiffrement et masquage des données sensibles (numéros de sécurité sociale, informations personnelles)
- **Créer un flux de données automatisé** de bout en bout, de la génération à la visualisation
- **Optimiser le stockage et les requêtes** pour des performances maximales avec BigQuery
- **Fournir des insights visuels** via un tableau de bord interactif dans Looker Studio

## Architecture du Pipeline

### 1. Génération de Données (Extract)
- **Bibliothèque Faker** : Génération automatique de données fictives d'employés réalistes
- **Données générées** : 
  - Informations personnelles (nom, prénom, âge, adresse)
  - Informations professionnelles (département, poste, salaire)
  - Données sensibles (numéro de sécurité sociale, email)
- **Format initial** : CSV structuré
- **Stockage** : Upload dans Google Cloud Storage (GCS) bucket

### 2. Transformation des Données (Transform)
Configuration d'une instance Cloud Fusion pour orchestrer les transformations :

- **Fusion de colonnes** : Concaténation du prénom et du nom en un seul champ `nom_complet`
- **Masquage de données** : Application de techniques de masquage sur les informations sensibles (ex: affichage partiel du numéro de sécurité sociale)
- **Chiffrement** : Chiffrement des champs critiques pour la conformité RGPD
- **Nettoyage** : Suppression des valeurs nulles, normalisation des formats, validation des données
- **Enrichissement** : Ajout de métadonnées (timestamp de traitement, version du pipeline)

### 3. Chargement et Stockage (Load)
- **Destination** : BigQuery (entrepôt de données)
- **Schéma optimisé** : Tables partitionnées par date pour améliorer les performances
- **Indexation** : Création d'index sur les colonnes fréquemment requêtées

### 4. Visualisation et Analyse
- **Looker Studio** : Création de dashboards interactifs
- **Métriques clés** : 
  - Distribution des employés par département
  - Analyse des salaires par poste
  - Évolution des effectifs dans le temps
  - Indicateurs RH personnalisables

## Technologies utilisées

### Services Google Cloud Platform
- **Google Cloud Storage (GCS)** : Stockage en ligne de fichiers dans des buckets accessibles, utilisé comme source de données pour le pipeline ETL
- **Cloud Fusion** : Plateforme d'intégration de données permettant de créer des pipelines visuels, d'automatiser les flux de données entre services
- **Data Fusion** : Outil de gestion et transformation des données, permettant de nettoyer, enrichir et masquer les informations avant le chargement
- **BigQuery** : Entrepôt de données serverless pour l'analyse rapide de gros volumes de données avec SQL
- **Looker Studio** : Outil de visualisation de données pour créer des tableaux de bord interactifs

### Langages et Bibliothèques
- **Python 3.10+** : Langage principal pour la génération de données
- **Faker** : Bibliothèque de génération de données fictives réalistes
- **pandas** : Manipulation et structuration des données CSV
- **google-cloud-storage** : SDK Python pour interagir avec GCS

### Sécurité et Conformité
- **Chiffrement au repos** : Données chiffrées dans GCS et BigQuery
- **Chiffrement en transit** : Communication sécurisée entre services via HTTPS
- **Masquage de données** : Techniques de pseudonymisation pour la conformité RGPD
- **Contrôle d'accès IAM** : Gestion fine des permissions par service
